# Console captures (verbatim)

The text in these files was printed to stdout during the 2026-10-10 Claude Code session and copied verbatim
from the session's tool output. It was **not** written to a file on the box at the time. Where a file on the
box exists for the same output (for example `box/logs/step6.log`), that file is the primary record, and the
capture here only adds output that exists nowhere else, mainly the raw text of individual model attempts,
which `report.py`/`serve.py` do not record.

Times are UTC (the laptop clock was UTC-4; the box logs are UTC). Box SSH address, port and API keys are
omitted on purpose.
